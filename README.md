## ✨ Fitur

- 🎨 Desain modern dan responsif (mobile, tablet, desktop)
- 🌈 Tema warna merah maroon yang elegan
- ⚡ Loading cepat dengan CDN
- 📱 Tampilan optimal di semua ukuran layar
- 🎭 Animasi halus (AOS - Animate On Scroll)
- ⌨️ Efek ketik dinamis (Typed.js)
- 🔍 Filter portofolio interaktif (Isotope)
- 📊 Counter statistik animasi (PureCounter)
- 📧 Form kontak fungsional

---

## 🛠️ Teknologi yang Digunakan

| Kategori | Teknologi |
|---|---|
| **Frontend** | HTML5, CSS3, JavaScript |
| **Framework CSS** | Bootstrap 5.3 |
| **Library** | AOS, Typed.js, PureCounter, Isotope, GLightbox, Swiper |
| **Icons** | Bootstrap Icons |
| **Fonts** | Google Fonts (Roboto, Raleway) |
| **Backend** | PHP (untuk form kontak) |
| **Hosting** | GitHub Pages |
