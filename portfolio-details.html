Deskripsi Proyek

Sistem Surat Masuk & Keluar adalah aplikasi berbasis web yang dirancang untuk mendigitalisasi proses administrasi surat di Sekretariat Daerah Kabupaten Pekalongan. Sebelumnya, pencatatan surat dilakukan secara manual menggunakan buku agenda, yang rentan terhadap kehilangan data dan sulit dicari kembali.

Dengan sistem ini, proses pencatatan, pencarian, dan pelaporan surat menjadi jauh lebih cepat, akurat, dan terorganisir. Sistem ini dibangun menggunakan PHP native dan MySQL sebagai database, dengan antarmuka yang sederhana namun fungsional.

Fitur Utama

  • Login admin (autentikasi pengguna)
  • Input surat masuk
  • Input surat keluar
  • Edit dan hapus data surat
  • Pencarian surat berdasarkan nomor/tanggal
  • Cetak / disposisi surat
  • Laporan surat bulanan

Tanggung Jawab Saya

  • Merancang struktur database MySQL
  • Membangun backend menggunakan PHP native
  • Membuat antarmuka responsif dengan Bootstrap
  • Testing dan debugging sistem
  • Dokumentasi penggunaan aplikasi

Hasil & Dampak

Sistem ini berhasil mengurangi waktu pencarian surat dari yang sebelumnya memakan waktu belasan menit menjadi hanya hitungan detik. Selain itu, risiko kehilangan data surat dapat diminimalisir karena semua data tersimpan secara digital dan ter-backup.
